# x402 and the crawler toll (separate project)

Written 2026-11-27 by the local session that owns x402, so the migration work
and the toll don't clash. That session runs on Martin's PC. Coordinate through
Martin before touching anything listed here.

## Decisions (Martin; don't re-ask)

- **One wallet for all x402 revenue, every brand:**
  `0x04A21ed5f6a46E4331860c87cce281f0DFDdE313`, Base mainnet, USDC, settled by
  Coinbase's CDP facilitator. No site hardcodes its own wallet.
- **Crawler toll:** only visitors Cloudflare labels **AI Crawler** pay. Search
  engines, AI search, AI assistants and people pass free.
- **Price:** $100,000 per pass. A pass opens each page on every site for one
  visit; reading a page again takes a new pass; passes do not stack.
- `robots.txt`, `llms.txt`, sitemaps and `/.well-known/*` stay free to all.

## Where the code is

Local only on Martin's PC (not on GitHub yet):

- `Desktop\x402-shared` — the shared x402 module (wallet, network, facilitator).
- `Desktop\x402-toll` — the toll: a Worker plus one Durable Object per paying
  wallet. Its README lists what is and isn't proven.

## Status

- Live **only** on its own test address:
  https://x402-toll-test.martingawlak.workers.dev (one-cent price, no routes,
  example.com behind it). It issues real bills through Coinbase.
- **Not in front of any site.** The production config is not deployed.
- No real payment has gone through it yet.

## How it will attach (planned, not done)

- A Worker **route** `<domain>/*` for each site, in front of the site's own
  Worker custom domain or Pages project. People and free crawlers pass straight
  through to the site unchanged.
- **accounts.martingawlakcompany.com stays outside the toll.**
- It adds one Worker request to every visit, which counts toward the Workers
  Free daily cap.

## Please avoid (without Martin)

- Adding Worker routes on these site hostnames.
- Turning on Cloudflare AI Crawl Control blocking or Pay Per Crawl on these
  zones. Either would act before the toll does.
- A `robots.txt` that blocks the AI crawlers outright. Letting them in is fine
  and matches the plan: the toll bills them.
- Making `robots.txt`, `llms.txt` or sitemaps require sign-in or payment.
