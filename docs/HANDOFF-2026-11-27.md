## How deploys work (important)

- This cloud workspace has a Cloudflare API token saved for
  `api.cloudflare.com` (account `923d5f4feee48b70c60bf0e1e8d5a378`). Use it with
  `CLOUDFLARE_API_TOKEN=dummy` (the proxy swaps in the real one). It can create
  D1 databases, run migrations and SQL, set secrets, and manage Workers/KV/Pages.
- **It cannot upload static assets**: wrangler's asset upload sends its own
  one-time key in the Authorization header and the proxy replaces it (401). So
  **any deploy of a Worker with assets is done by Martin from his PC**, where
  wrangler signs in itself. He has done this; give him exact commands, one per
  line. His clones: `Desktop\dod-zora-new`, `Desktop\mgc-platform` (this repo),
  `Desktop\bandturo-new`, `Desktop\zora-site` (BabyZora). Each deploy:
  `git pull`, then `npx.cmd wrangler deploy --env preview` (or no `--env` for
  production) from the app folder.
- npm's "allow-scripts" warning on his PC is harmless so far; if esbuild ever
  fails, `npm approve-scripts esbuild workerd` then `npm install`.
- R2 is not enabled on the account (needs the dashboard). Sites run without it;
  uploads (DoD pressings/mockups, Bandturo's `wp-content/uploads`, commission
  files) need it before cutover.

   (`POST /api/admin/brand-clients` with `{"origin":"https://<site>"}` while
   signed in as the admin at accounts.martingawlakcompany.com) returns a
   client id + secret → `SSO_CLIENT_ID` var / `SSO_CLIENT_SECRET` secret.
2. **Secrets** (listed in each site's `wrangler.toml` header and MIGRATION.md):
   `SESSION_SECRET` (generate), email (`RESEND_API_KEY` or Cloudflare Email
   Sending), and per site:

     plain text — move funds, then `GIFT_KEY`/`BUYBACK_KEY`), `ZORA_API_KEY`,
     `PRINTFUL_TOKEN`, `PAYPAL_SECRET`, `GDRIVE_CLIENT_SECRET`, Stripe.
   - Farm: `GOOGLE_GEOCODE_KEY`, `GDRIVE_SA_JSON`, `AT_CHECK_TOKEN`,
     `WP_AUTH_SALT` only if old garden links must keep working (one customer;
     resending is simpler), Stripe.
   - Bandturo: PayPal, Printful, Facebook (see its MIGRATION.md).
   - Stripe (DoD + farm): a restricted key with Customers: Write and Checkout
